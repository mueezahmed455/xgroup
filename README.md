# X.Group

The operating layer for growing firms.

London startup building automation infrastructure — workflows, multi-tenant isolation, and a real-time control plane.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Three.js + React Three Fiber
- GSAP + Framer Motion
- Lenis smooth scroll

## Develop

```bash
pnpm install
pnpm dev
```

## Deploy

Configured for Vercel. Set `RESEND_API_KEY` and `NEXT_PUBLIC_SITE_URL` in the environment.

Live: https://xgroup-web.vercel.app
